# 内存

## swap
### 创建swapfile
查看内存
- free -h

创建文件
- fallocate -l 10G /swapfile

修改权限
- chmod 600 /swapfile

格式化swap
- mkswap /swapfile

启用swap
- swapon /swapfile

验证
- free -h 或 swapon --show

永久生效
- echo "/swapfile none swap defaults 0 0" >> /etc/fstab

删除swap
- swapoff /swapfile
- rm -f /swapfile
- 删除/etc/fstab 中相关行
